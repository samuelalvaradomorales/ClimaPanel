# Antes de comenzar

1. Lea completamente `GUIA_POSTULANTE.pdf`.
2. Ejecute `VALIDAR.cmd` o `dotnet restore`, `dotnet build` y `dotnet test`.
3. Inicie Git local antes de modificar el código.
4. No publique el repositorio hasta que cierre la ventana común de evaluación.
5. Complete `DECISIONS.md` y `AI_USAGE.md` antes de entregar.
